### 1. Introduction

The software engineering outcome discussed in this repository, **interlace-ex**, consolidates 57 GB of uncompressed gene and disease information into 1.4 GB of refined **interlace-go** binary data assets. 15 Go [applications](./cmd/README.md) are created to demonstrate how to use the **interlace-go** [packages](https://github.com/sas-quantome/interlace-go).
